# Security policy

## Reporting a vulnerability

Please report it privately through
[GitHub's private vulnerability reporting](https://github.com/noeto-tasks/noeto-mcp/security/advisories/new),
not in a public issue.

Include the version (the image tag, or the one the server logs on start), how to reproduce
it, and what an attacker gains. You will get an answer within a few days.

## Supported versions

Fixes go into the latest release only. The Docker image, Homebrew cask and
binaries are all published from the same tag.
